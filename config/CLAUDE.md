# Ecomdrop Bootcamp — instrucciones globales

- Responde siempre en español.
- Este equipo opera tiendas Shopify con el **SIE (Super Inteligencia Ecommerce)**. Las reglas, skills y trampas viven
  en la carpeta `sie/` de cada tienda (`@sie/CLAUDE.md`). Trabaja siempre dentro de la carpeta de una tienda.
- Las claves van en `.env` y nunca se escriben en el código, en `tienda.json` ni en mensajes.
- Si falta una herramienta o una clave, corre `ecomdrop-doctor` y luego la skill `/setup-proyecto`. No improvises instalaciones.
- Antes de escribir en Shopify, Meta o el bot de WhatsApp, confirma que el conector apunta a la tienda correcta
  (ver `sie/conocimiento/mcp-y-cuentas.md`).
